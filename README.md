# Time-Series

This project focuses on forecasting daily values for a period spanning from
April 1st, 2015 to November 7th, 2015. We’ll employ three different approaches:
ARIMA modelling, UCM (Unobserved Components Model), and Machine Learn-
ing techniques. To evaluate our predictions, we’ll primarily use Mean Absolute
Error (MAE), while also considering Akaike Information Criterion (AIC) and
Bayesian Information Criterion (BIC) metrics specifically for the ARIMA and
UCM models. Our historical data covers over eight years, running from Jan-
uary 4th, 2007 through March 31st, 2015. This project was done using Python
language.
